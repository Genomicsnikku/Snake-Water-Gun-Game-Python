# 🐍💧🔫 Snake-Water-Gun Game - Python

A Python implementation of the classic Snake, Water, Gun game - similar to Rock, Paper, Scissors!

### 📜 Rules
* Snake (s) drinks Water (w) -> Snake wins
* Water (w) douses Gun (g) -> Water wins
* Gun (g) kills Snake (s) -> Gun wins

### 💻 How to Play
1. Run the file: `python snake_water_gun.py`
2. Enter s, w, or g when asked
3. See if you beat the computer!

### 🧠 Concepts Used
* `random` module
* Functions
* Conditionals & Loops
* Dictionary for mapping
